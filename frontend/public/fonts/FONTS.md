Font provenance (licenses follow in OFL.txt):

- inter.woff2 / inter-italic.woff2 — Inter variable fonts, SIL OFL 1.1.
- archivo.woff2 — Archivo variable font, Latin subset with BOTH variable axes
  (wght 100–900, wdth 62–125; default instance SemiBold). Subsetted from
  google/fonts ofl/archivo/Archivo[wdth,wght].ttf using fontTools subset
  (layout features: kern,liga,calt,ccmp,mark,mkmk,locl), SIL OFL 1.1.
  The wdth axis backs `font-stretch: 125%` ("Archivo Expanded") on the
  brand/hero display roles declared in src/styles/tokens.css.
- archivo-italic.woff2 — earlier wght-only italic build, SIL OFL 1.1.
- Previous weight-only archivo.woff2 is archived at archive/fonts/.
